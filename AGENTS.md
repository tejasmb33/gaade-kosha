# GAADE KOSHA project rules
- Work in project/; preserve user data. No cloud deployment or Git push.
- Public data must be sourced and explicitly human-approved. Never invent proverbs, provenance, dialects, or verified meanings.
- Imports and contributions are pending. Review and FTS updates share a transaction.
- Local inference is optional and never downloads models. Only the two approved local models are allowed.
- User subsequently authorized optional OpenAI/Gemini/Groq situation reasoning and web fallback. Keep cloud requests opt-in, keys backend-only, and web references visibly unverified. Never auto-import or approve external findings.
- Preserve Kannada combining marks and original recordings/transcripts. Keep moderation tokens and audio private.
- Test with isolated temporary data and explicitly synthetic fixtures. Report real AI/cultural evaluation separately.
- Run backend/launcher tests, frontend build, and isolated browser journeys after relevant changes.
