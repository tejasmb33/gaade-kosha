# ಗಾದಾಮೃತ · GAADAMRUTHA

**ಗಾದೆಗಳ ಸೊಗಡಿನಲ್ಲಿ ಅನುಭವದ ಅಮೃತ.**

ದೈನಂದಿನ ಸಂದರ್ಭಕ್ಕೆ ಹೊಂದುವ ಕನ್ನಡ ಗಾದೆಯನ್ನು ಹುಡುಕಿ, ಅದರ ಅರ್ಥ ಮತ್ತು ಬಳಕೆಯನ್ನು ತಿಳಿದುಕೊಳ್ಳಲು ನೆರವಾಗುವ ಜಾಲತಾಣ. ಸಂದರ್ಭವನ್ನು ಟೈಪ್ ಮಾಡಬಹುದು ಅಥವಾ ಧ್ವನಿ ಮೂಲಕ ನೀಡಬಹುದು. ಗಾದೆ ನಿಘಂಟು ಮತ್ತು ಕರ್ನಾಟಕದ ಜಿಲ್ಲೆಗಳ ಪರಿಚಯವೂ ಲಭ್ಯವಿದೆ.

## ಪ್ರಸ್ತುತ ಸ್ಥಿತಿ — 19 ನವೆಂಬರ್ 2026

ಈ ಎಣಿಕೆಗಳು **ಸ್ಥಳೀಯ ದತ್ತಸಂಚಯ ಮತ್ತು ಕಡತಗಳಿಗೆ** ಅನ್ವಯಿಸುತ್ತವೆ. ಈ README ಪರಿಷ್ಕರಣೆಯಲ್ಲಿ production ದತ್ತಸಂಚಯವನ್ನು ಪರಿಶೀಲಿಸಿಲ್ಲ.

APPROVED ಎಂದರೆ ಯೋಜನೆಯ ಬಳಕೆದಾರರು ಪ್ರಕಟಣೆಗೆ ಒಪ್ಪಿದ್ದಾರೆ ಎಂದರ್ಥ. ಇದು ಅನುವಾದ, ಅರ್ಥ, ಮೂಲ ಅಥವಾ ಉಚ್ಚಾರಣೆಗೆ ಸ್ವತಂತ್ರ ಸಾಂಸ್ಕೃತಿಕ ಪರಿಶೀಲನೆ ನಡೆದಿರುವುದಕ್ಕೆ ಸಾಕ್ಷಿಯಲ್ಲ.

## ಲಭ್ಯವಿರುವ ವೈಶಿಷ್ಟ್ಯಗಳು

- **ಮುಖಪುಟದ ಸಂಭಾಷಣೆ:** ಸಂದರ್ಭವನ್ನು ನೀಡಿ ಹೊಂದುವ ಅನುಮೋದಿತ ಗಾದೆಗಳನ್ನು ಪಡೆಯಬಹುದು. ಹೊಸ ಪ್ರಶ್ನೆಯ ಆರಂಭ ಓದುವ ಸ್ಥಳದಲ್ಲೇ ಉಳಿಯುತ್ತದೆ; ಉತ್ತರ ಬಂದಾಗ ಕೆಳಕ್ಕೆ ಬಲವಂತವಾಗಿ scroll ಆಗುವುದಿಲ್ಲ.
- **ಹುಡುಕಾಟದ ಆಯ್ಕೆ:** ಸಾಮಾನ್ಯ ಸ್ಥಳೀಯ ಹುಡುಕಾಟ ಅಥವಾ ಆಯ್ದ Gemini/Groq ಸೇವೆ. ಪ್ರಸ್ತುತ ವಿಧಾನವು ಸಂದರ್ಭ ಮತ್ತು ಸಂಕ್ಷಿಪ್ತ ಅನುಮೋದಿತ ಸಂಗ್ರಹವನ್ನು ಒಂದೇ ಆಯ್ಕೆ ವಿನಂತಿಯಲ್ಲಿ ಕಳುಹಿಸುತ್ತದೆ. ನಿಧಾನವಾಗಿದ್ದ ಎರಡು ಹಂತದ combined workflow ತೆಗೆದುಹಾಕಲಾಗಿದೆ. ಸ್ಪಷ್ಟವಾಗಿ ಸಕ್ರಿಯಗೊಳಿಸಿದ web fallback ಇದ್ದರೆ ಹೊಂದಾಣಿಕೆ ಇಲ್ಲದಾಗ ಹೆಚ್ಚುವರಿ ವಿನಂತಿ ಹೋಗಬಹುದು.
- **ಗಾದೆ ನಿಘಂಟು:** ಆರು ವಿಷಯಗಳು — ಹಣ (`money`), ಕೆಲಸ (`work`), ಅಧ್ಯಯನ (`study`), ಕುಟುಂಬ (`family`), ಸ್ನೇಹಿತರು (`friends`), ವ್ಯಕ್ತಿತ್ವ (`character`). ಮೂಲ backend category ಉಪವರ್ಗವಾಗಿ ಹಾಗೆಯೇ ಉಳಿದಿದೆ.
- **ಎಲ್ಲೆಡೆ ಒಂದೇ ವಿವರ ಕ್ರಮ:** ಕನ್ನಡ ಗಾದೆ → ಇಂಗ್ಲಿಷ್ ಸಮಾನಾರ್ಥ/ರೂಪಾಂತರ → ಕನ್ನಡ ಅರ್ಥ → ಇಂಗ್ಲಿಷ್ ಅರ್ಥ → ಉದಾಹರಣೆ → ಪ್ರದೇಶ → ಸಂದರ್ಭ 1 ಮತ್ತು ಸಂದರ್ಭ 2, ಎರಡೂ ಭಾಷೆಗಳಲ್ಲಿ.
- **ಕನ್ನಡ ಧ್ವನಿ ವಿವರಣೆ:** chat ಮತ್ತು dictionaryಯಲ್ಲಿ “ವಿವರಣೆ ಕೇಳಿ”. ಧ್ವನಿ ಸೃಷ್ಟಿಗೆ provider ಸಂಪರ್ಕ, ಅನುಮತಿ ಮತ್ತು ಬಳಕೆಯ ಮಿತಿ ಅನ್ವಯಿಸುತ್ತವೆ. 200 ಪಠ್ಯಗಳು ಸಿದ್ಧವಿವೆ ಎಂದರೆ 200 ಧ್ವನಿಗಳನ್ನು ಕೇಳಿ ಪರಿಶೀಲಿಸಲಾಗಿದೆ ಎಂದಲ್ಲ.
- **ಧ್ವನಿ ಇನ್‌ಪುಟ್:** browser speech ಹಾಗೂ ಧ್ವನಿ ದಾಖಲಿಸಿ ಪಠ್ಯಕ್ಕೆ ಬದಲಿಸುವ ವಿಧಾನಗಳಿವೆ. ಪ್ರಸ್ತುತ SearchBox ಭಾಷೆ Englishಗೆ ನಿಗದಿಯಾಗಿದೆ; ನೈಜ ಕನ್ನಡ ಧ್ವನಿ ನಿಖರತೆ ಇನ್ನೂ ಸ್ಥಾಪಿತವಾಗಿಲ್ಲ.
- **ಕೊಡುಗೆ ಮತ್ತು ಪರಿಶೀಲನೆ:** ಹೊಸ ದಾಖಲೆಗಳು pending ಆಗುತ್ತವೆ. ಅನುಮೋದನೆಯ ಜೊತೆಗೆ search index ನವೀಕರಣ ಒಂದೇ transactionನಲ್ಲಿ ನಡೆಯುತ್ತದೆ. ಮೂಲ ಧ್ವನಿ ಮತ್ತು ಲಿಪ್ಯಂತರ ಪ್ರತ್ಯೇಕವಾಗಿ ಉಳಿಯುತ್ತವೆ.
- **ಕರ್ನಾಟಕದ ಜಿಲ್ಲೆಗಳು:** 31 ಜಿಲ್ಲೆಗಳ interactive ನಕ್ಷೆ, ಕನ್ನಡ ಹೆಸರುಗಳು ಮತ್ತು ಕನ್ನಡ/ಇಂಗ್ಲಿಷ್ ಮಾಹಿತಿ. ಇದು ಗಾದೆಗಳ ಪ್ರಾದೇಶಿಕ ಮೂಲಕ್ಕೆ ಸಾಕ್ಷಿಯಲ್ಲ.

`ಕರಡು`, `Draft`, `human verification` ಮೊದಲಾದ ಮುನ್ನುಡಿಗಳನ್ನು ಸಾಮಾನ್ಯ ವಿವರ ಪ್ರದರ್ಶನದಲ್ಲಿ ತೆಗೆದುಹಾಕಲಾಗಿದೆ. ಮೂಲ ಪಠ್ಯ ಮತ್ತು ಪರಿಶೀಲನಾ ಗುರುತುಗಳನ್ನು ದತ್ತಾಂಶದಲ್ಲಿ ಉಳಿಸಲಾಗಿದೆ. ಇಂಗ್ಲಿಷ್ ರೂಪಾಂತರವು ಕಡ್ಡಾಯವಾಗಿ ಪ್ರಚಲಿತ ಇಂಗ್ಲಿಷ್ ಗಾದೆಯ ಸಮಾನಾರ್ಥವಲ್ಲ.

## ಸ್ಥಳೀಯವಾಗಿ ಚಲಾಯಿಸುವುದು

Python 3.12, Node.js/npm ಮತ್ತು FFmpeg/ffprobe ಅಗತ್ಯ. ಯೋಜನೆಯ ಮೂಲ directoryಯಲ್ಲಿ:

```sh
cd project
.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
.venv/bin/python scripts/dev.py --check
.venv/bin/python scripts/dev.py
```

ಮೊದಲ ಬಾರಿಗೆ `.venv` ಇಲ್ಲದಿದ್ದರೆ `python3.12 -m venv .venv` ಮೂಲಕ ರಚಿಸಿ. ಪೂರ್ಣ local-model ವ್ಯವಸ್ಥೆ ಬೇಕಾದರೆ ಕೆಳಗಿನ ವಿಭಾಗವನ್ನೂ ನೋಡಿ.

ಮುಖಪುಟ: `http://localhost:5173` · API ವಿವರಗಳು: `http://localhost:8000/docs`.

Launcher `.env` ಓದುತ್ತದೆ; ಈಗಾಗಲೇ export ಮಾಡಿರುವ environment valuesಗೆ ಆದ್ಯತೆ ಇದೆ. `ADMIN_TOKEN` ಖಾಲಿ ಇದ್ದರೆ ಖಾಸಗಿ `data/admin-token` ಬಳಸುತ್ತದೆ. ಅದನ್ನು Review ಪುಟದಲ್ಲಿ ಸ್ಥಳೀಯವಾಗಿ ಬಳಸಿ; ಹಂಚಿಕೊಳ್ಳಬೇಡಿ. Ctrl+C ಎರಡೂ ಸೇವೆಗಳನ್ನು ನಿಲ್ಲಿಸುತ್ತದೆ. ನೇರ `uvicorn` ಚಾಲನೆ `.env` ಅನ್ನು ಸ್ವತಃ ಓದುವುದಿಲ್ಲ.

## ಸಂರಚನೆ ಮತ್ತು ಖಾಸಗಿತನ

`.env.example`ನ ಹೆಸರುಗಳನ್ನು ಆಧರಿಸಿ ಖಾಸಗಿ `.env` ಹೊಂದಿಸಿ. ನಿಜವಾದ ಕೀಗಳು ಮತ್ತು tokens README ಅಥವಾ Gitನಲ್ಲಿ ಇರಬಾರದು.

| ಹೆಸರು | ಬಳಕೆ |
|---|---|
| `GAADE_AI_PROVIDER` | `gemini` ಅಥವಾ `groq` |
| `GAADE_AI_MODEL` | Geminiಗಾಗಿ ಖಾತೆಗೆ ಲಭ್ಯವಿರುವ ಮಾದರಿ |
| `GEMINI_API_KEY` | backend Gemini ಪ್ರವೇಶ |
| `GROQ_API_KEY`, `GAADE_GROQ_MODEL` | backend Groq ಪ್ರವೇಶ |
| `GAADE_TTS_ENABLED`, `GAADE_TTS_MODEL` | ಕನ್ನಡ ಧ್ವನಿ ಸೃಷ್ಟಿ |
| `E5_MODEL_PATH`, `WHISPER_MODEL_PATH` | ಈಗಾಗಲೇ ಸ್ಥಾಪಿಸಿದ ಐಚ್ಛಿಕ ಸ್ಥಳೀಯ ಮಾದರಿಗಳು |
| `DATABASE_URL` | hosted PostgreSQL ಸಂಪರ್ಕ |
| `FRONTEND_ORIGIN` | backendಗೆ ಅನುಮತಿಸಲಾದ frontend origin |
| `VITE_BACKEND_ORIGIN` | frontendಗೆ ಸಾರ್ವಜನಿಕ backend URL ಮಾತ್ರ |

Cloud ಹುಡುಕಾಟ ಆಯ್ಕೆ ಮಾಡಿದಾಗ ಸಂದರ್ಭ ಮತ್ತು ಅನುಮೋದಿತ ಗಾದೆಯ metadata ಆಯ್ದ ಸೇವೆಗೆ ಹೋಗುತ್ತವೆ. API ಕೀಗಳು backendನಲ್ಲಿ ಮಾತ್ರ ಇರುತ್ತವೆ. ಬಾಹ್ಯ web ಉಲ್ಲೇಖಗಳು ಪರಿಶೀಲಿಸದವು; ಅವುಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ import ಅಥವಾ approve ಮಾಡುವುದಿಲ್ಲ.

## ಐಚ್ಛಿಕ ಸ್ಥಳೀಯ ಮಾದರಿಗಳು

`MODELS.json`ನಲ್ಲಿ ಅನುಮೋದಿತ snapshot ವಿವರಗಳಿವೆ: `intfloat/multilingual-e5-small` ಮತ್ತು `mlx-community/whisper-small-mlx`. Runtime ಮಾದರಿಗಳನ್ನು download ಮಾಡುವುದಿಲ್ಲ. MLX speechಗೆ ಹೊಂದುವ Apple Silicon/Mac ವ್ಯವಸ್ಥೆ ಅಗತ್ಯ; hosted speech ಪ್ರತ್ಯೇಕ provider ಬಳಸಬಹುದು.

```sh
.venv/bin/python -m pip install -r backend/requirements-ai.txt
.venv/bin/python scripts/download_models.py --inspect
# ನೇರವಾಗಿ download ಮಾಡಲು ಬಯಸಿದಾಗ ಮಾತ್ರ:
.venv/bin/python scripts/download_models.py --download
.venv/bin/python scripts/check_models.py
```

[ದತ್ತಾಂಶ README](datasets/README.md) ಮತ್ತು [ಸಲ್ಲಿಕೆ README](datasets/submission/README.md)ಯಲ್ಲಿ ಪೂರ್ಣ ವಿವರಣೆ ಇದೆ.

- `datasets/submission/gaade.csv`: 200 ಗಾದೆಗಳು; ಬೇಕಾದ ಮುಖ್ಯ ಕ್ಷೇತ್ರಗಳು ಮತ್ತು `gaade_id`.
- `datasets/submission/situations.csv`: 400 ದ್ವಿಭಾಷಾ ಸಂದರ್ಭಗಳು; ಪ್ರತಿ `gaade_id`ಗೆ ಎರಡು ಸಾಲುಗಳು.

- `datasets/submission/validation.json`: ಎಣಿಕೆಗಳು ಮತ್ತು CSVಗಳ SHA-256 ಮೌಲ್ಯಗಳು.

```sh

.venv/bin/python scripts/export_submission.py
# ಸಿದ್ಧವಿರುವ ದ್ವಿಭಾಷಾ ಸಂದರ್ಭಗಳನ್ನು export ಮಾಡಲು:
.venv/bin/python scripts/export_bilingual_situations.py
# ದ್ವಿಭಾಷಾ ವಿವರಗಳ ಲಭ್ಯತೆ ಪರಿಶೀಲಿಸಲು — cloud ಕರೆ ಇಲ್ಲ:
.venv/bin/python scripts/prepare_bilingual_display.py
```

**ಗಮನಿಸಿ:** submission export ಅನ್ನು ಪುನಃ ನಡೆಸಿದರೆ CSVಯಲ್ಲಿ ಕೈಯಾರೆ ಹಾಕಿದ random ಪ್ರದೇಶಗಳು ತೆಗೆದುಹೋಗಿ, backendನಲ್ಲಿ ಇರುವ ನಿಜವಾದ ಮೌಲ್ಯಗಳು ಬರುತ್ತವೆ; ಈಗ ಅವು ಖಾಲಿ. Database ಮತ್ತು export ಕಡತಗಳು ಪ್ರತ್ಯೇಕ.

## ಪರೀಕ್ಷೆಗಳು ಮತ್ತು ಫಲಿತಾಂಶಗಳ ಮಿತಿ

ಇತ್ತೀಚಿನ backend ಪರೀಕ್ಷೆಗಳು: **44 passed, 1 skipped**. Frontend build ಮತ್ತು ಪ್ರತ್ಯೇಕ chat, dictionary, recording/narration browser journeys ಉತ್ತೀರ್ಣವಾಗಿವೆ. Browser ಪರೀಕ್ಷೆಗಳು synthetic fixtures ಮತ್ತು mock speech/provider responses ಬಳಸುತ್ತವೆ.

```sh
.venv/bin/python -m pytest backend/tests -q
npm run build --prefix frontend
node frontend/tests/chat.cjs
node frontend/tests/dictionary.cjs
node frontend/tests/recording.cjs
```

Browser ಪರೀಕ್ಷೆಗಳಿಗೆ ಹೊಂದುವ Playwright Chromium ಅಗತ್ಯ. ಬೇಕಾದರೆ `PLAYWRIGHT_CHROMIUM_EXECUTABLE`ನಲ್ಲಿ ಅದರ executable path ನೀಡಿ. ನಿಜವಾದ ದತ್ತಾಂಶವನ್ನು ಪರೀಕ್ಷಾ fixtures ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

ಹಳೆಯ ಸ್ಥಳೀಯ retrieval ಪರೀಕ್ಷೆಯಲ್ಲಿ 108 draft ಉದಾಹರಣೆಗಳಲ್ಲಿ 76 ಹೊಂದಾಣಿಕೆಗಳು ಬಂದಿದ್ದವು (~70.4%). ಇದು ಈಗಿನ 200 ಗಾದೆಗಳ ಅಥವಾ Gemini/Groqಯ ಸಾಮಾನ್ಯ ನಿಖರತೆಯ ಅಳತೆ ಅಲ್ಲ. ನೈಜ ಕನ್ನಡ ಮಾತು, ಸಾಂಸ್ಕೃತಿಕ ಸೂಕ್ತತೆ ಮತ್ತು ಧ್ವನಿ ಉಚ್ಚಾರಣೆಗೆ ಪ್ರತ್ಯೇಕ ಮಾನವ ಪರೀಕ್ಷೆ ಅಗತ್ಯ.

## ಇನ್ನೂ ಉಳಿದಿರುವ ಕೆಲಸ

- ಹಿರಿಯರಿಂದ ಸಂಗ್ರಹಿಸಿದ ಮೂಲ ದಾಖಲೆಗಳು, ನಿಜವಾದ collector/region ಮಾಹಿತಿ ಮತ್ತು signed consent.
- ಪ್ರತಿ ಗಾದೆಗೆ ಮಾನವ ಓದಿನ 16 kHz mono WAV; ಈಗ ಸಂಬಂಧಿತ recordings tableನಲ್ಲಿ 0 ದಾಖಲೆಗಳಿವೆ.
- ಅರ್ಥ, ಅನುವಾದ ಮತ್ತು 400 ಸಂದರ್ಭಗಳ ಸ್ವತಂತ್ರ ಕನ್ನಡ/ಸಾಂಸ್ಕೃತಿಕ ಪರಿಶೀಲನೆ.
- ನೈಜ Kannada voice input ಮತ್ತು ವಿವಿಧ browser/device ಪರೀಕ್ಷೆಗಳು.
- Peer review, ಹಕ್ಕು/ಪರವಾನಗಿ ದೃಢೀಕರಣ, ಅಂತಿಮ demo video ಮತ್ತು organizer submission evidence.

CSVಯ random ಪ್ರದೇಶಗಳು ಈ ಕೊರತೆಯನ್ನು ಪೂರೈಸುವುದಿಲ್ಲ. ಎಲ್ಲ 200 ಗಾದೆಗಳಿಗೆ public website ಮೂಲಗಳ ಉಲ್ಲೇಖವಿದೆ; ಹಿರಿಯರಿಂದ ನೇರವಾಗಿ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ ಎಂಬ ಸಾಕ್ಷಿ ಇಲ್ಲ.

## Hosting ಮತ್ತು ಆವೃತ್ತಿಗಳು

Frontendಗೆ Vercel, backendಗೆ Render ಮತ್ತು PostgreSQL/private storageಗೆ Supabase ಬಳಸುವ ಸಂರಚನೆ ಇದೆ. [Deployment ಸೂಚನೆಗಳು](deployment/README.md) ನೋಡಿ. ಖಾಸಗಿ local database, translation/display caches ಮತ್ತು audio Git push ಜೊತೆಗೆ hosted ವ್ಯವಸ್ಥೆಗೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಹೋಗುವುದಿಲ್ಲ. Local data migration ಮತ್ತು code deployment ಬೇರೆ ಕ್ರಮಗಳು.

ಈ README ನವೀಕರಣದಲ್ಲಿ Git push ಅಥವಾ cloud deployment ಮಾಡಿಲ್ಲ. ಹಿಂದೆ ರಚಿಸಿದ rollback tag `v1.0` ಇದೆ; ಬಳಸುವ ಮುನ್ನ ಅದರ commit ಮತ್ತು ಬೇಕಾದ ದತ್ತಾಂಶ backup ಪರಿಶೀಲಿಸಿ. [Rollback ಸೂಚನೆಗಳು](deployment/ROLLBACK.md).

ಹಳೆಯ setup ವಿವರಗಳು ಮತ್ತು ದಿನಾಂಕವಾರು ಪರೀಕ್ಷಾ ಟಿಪ್ಪಣಿಗಳನ್ನು [ತಾಂತ್ರಿಕ ಇತಿಹಾಸ](docs/technical-history.md)ದಲ್ಲಿ ಉಳಿಸಲಾಗಿದೆ; ಅವು ಪ್ರಸ್ತುತ ಸ್ಥಿತಿಯ ವರದಿ ಅಲ್ಲ.
