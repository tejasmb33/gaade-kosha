# ಗಾದಾಮೃತ — 5 ನಿಮಿಷದ ಕನ್ನಡ ಡೆಮೊ ಸ್ಕ್ರಿಪ್ಟ್

ಅವಧಿ: ಸುಮಾರು 5 ನಿಮಿಷ. ಕೆಳಗಿನ ಸಮಯ ಹಂಚಿಕೆಯಲ್ಲಿ ಮಾತು, ಪುಟ ಬದಲಾವಣೆ ಮತ್ತು ಧ್ವನಿ ಕೇಳಿಸುವ ವಿರಾಮಗಳು ಸೇರಿವೆ. ಒಂದು ಬಾರಿ ಅಭ್ಯಾಸ ಮಾಡಿ ನಿಮ್ಮ ಮಾತಿನ ವೇಗಕ್ಕೆ ಹೊಂದಿಸಿ. ಚೌಕ ಆವರಣದಲ್ಲಿರುವ ಸೂಚನೆಗಳನ್ನು ಓದಬೇಡಿ; ಅವು ಪರದೆಯಲ್ಲಿ ತೋರಿಸಬೇಕಾದ ಕ್ರಿಯೆಗಳು.

## 0:00–0:25 · ಪರಿಚಯ

[ಮುಖಪುಟದ ಆರಂಭಿಕ animation, logo ಮತ್ತು ಹೆಸರನ್ನು ತೋರಿಸಿ.]

ನಮಸ್ಕಾರ! ನಮ್ಮ ಯೋಜನೆಯ ಹೆಸರು **ಗಾದಾಮೃತ**. ನಮ್ಮ ಧ್ಯೇಯವಾಕ್ಯ, **“ಗಾದೆಗಳ ಸೊಗಡಿನಲ್ಲಿ ಅನುಭವದ ಅಮೃತ.”**

ಕನ್ನಡ ಗಾದೆಗಳು ನಮ್ಮ ಹಿರಿಯರ ಅನುಭವ ಮತ್ತು ಬದುಕಿನ ತಿಳಿವಳಿಕೆಯನ್ನು ಕೆಲವೇ ಪದಗಳಲ್ಲಿ ಹೇಳುತ್ತವೆ. ಆದರೆ ಒಂದು ನಿರ್ದಿಷ್ಟ ಸಂದರ್ಭದಲ್ಲಿ ಯಾವ ಗಾದೆಯನ್ನು ಬಳಸಬೇಕು ಎಂಬುದು ತಕ್ಷಣ ನೆನಪಾಗದೇ ಇರಬಹುದು. ಈ ಸಮಸ್ಯೆಗೆ ನೆರವಾಗಲು ನಾವು ಗಾದಾಮೃತವನ್ನು ಅಭಿವೃದ್ಧಿಪಡಿಸಿದ್ದೇವೆ.

## 0:25–1:15 · ಸಂದರ್ಭದಿಂದ ಗಾದೆ ಹುಡುಕಾಟ

[ಮುಖಪುಟದಲ್ಲಿ Gemini ಆಯ್ಕೆಯನ್ನು ತೋರಿಸಿ. ಕೆಳಗಿನ ಪಠ್ಯವನ್ನು ಮೊದಲೇ clipboardನಲ್ಲಿ ಇಟ್ಟುಕೊಳ್ಳಿ.]

ಇಲ್ಲಿ ಬಳಕೆದಾರರು ತಮ್ಮ ಸಂದರ್ಭವನ್ನು ಕನ್ನಡ ಅಥವಾ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ಬರೆಯಬಹುದು. ಉದಾಹರಣೆಗೆ, ನಾನು ಈ ಸಂದರ್ಭವನ್ನು ನೀಡುತ್ತಿದ್ದೇನೆ:

**“ಹಣದ ತೊಂದರೆಯಿಂದ ಅವಳು ಓದನ್ನು ಬಿಡಬೇಕಾದ ಪರಿಸ್ಥಿತಿ ಬಂತು. ಆದರೆ ಅರೆಕಾಲಿಕ ಕೆಲಸ ಮಾಡಿ, ವಿದ್ಯಾರ್ಥಿವೇತನ ಪಡೆದು, ತನ್ನ ಶಿಕ್ಷಣವನ್ನು ಪೂರ್ಣಗೊಳಿಸಿದಳು.”**

[ಹುಡುಕಾಟ ಒತ್ತಿ. ಉತ್ತರ ಬರುತ್ತಿರುವಾಗ ಮುಂದಿನ ಸಾಲುಗಳನ್ನು ಹೇಳಿ.]

ಹುಡುಕಾಟಕ್ಕೆ ಸಾಮಾನ್ಯ ವಿಧಾನ, ಜೆಮಿನಿ ಅಥವಾ ಗ್ರೋಕ್ ಆಯ್ಕೆ ಮಾಡಬಹುದು. ಆಯ್ದ ಸೇವೆಯು ಸಂದರ್ಭದ ಮುಖ್ಯ ಭಾವವನ್ನು ಅರ್ಥಮಾಡಿಕೊಂಡು, ನಮ್ಮ ಅನುಮೋದಿತ ದತ್ತಸಂಚಯದಿಂದ ಹೊಂದುವ ಗಾದೆಯನ್ನು ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ. ಇಲ್ಲಿ ಕೇವಲ “ಹಣ” ಎಂಬ ಪದಕ್ಕಿಂತ, ಪರಿಶ್ರಮ ಮತ್ತು ದೃಢಸಂಕಲ್ಪದಿಂದ ಅಡೆತಡೆಗಳನ್ನು ದಾಟಿರುವುದು ಮುಖ್ಯ.

[ಬಂದಿರುವ ನಿಜವಾದ ಫಲಿತಾಂಶವನ್ನು ತೋರಿಸಿ; ಮೊದಲೇ ನಿರ್ದಿಷ್ಟ ಗಾದೆ ಬರುತ್ತದೆಂದು ಹೇಳಬೇಡಿ.]

ಉತ್ತರವು ಹಂತ ಹಂತವಾಗಿ ಕಾಣಿಸುತ್ತದೆ. ಪ್ರಶ್ನೆಯ ಆರಂಭದಲ್ಲೇ ಓದುವ ಸ್ಥಾನ ಉಳಿಯುವುದರಿಂದ ಬಳಕೆದಾರರಿಗೆ ಮೇಲಕ್ಕೆ ಹುಡುಕಿಕೊಂಡು ಹೋಗುವ ಅಗತ್ಯ ಕಡಿಮೆಯಾಗುತ್ತದೆ.

## 1:15–2:00 · ದ್ವಿಭಾಷಾ ವಿವರ ಮತ್ತು ಧ್ವನಿ

[ಒಂದು ಫಲಿತಾಂಶದ ವಿಭಾಗಗಳನ್ನು ನಿಧಾನವಾಗಿ scroll ಮಾಡಿ.]

ಪ್ರತಿ ಗಾದೆಯ ವಿವರವನ್ನು ಒಂದೇ ಕ್ರಮದಲ್ಲಿ ನೀಡಿದ್ದೇವೆ: ಕನ್ನಡ ಗಾದೆ, ಇಂಗ್ಲಿಷ್ ರೂಪಾಂತರ, ಕನ್ನಡ ಅರ್ಥ, ಇಂಗ್ಲಿಷ್ ಅರ್ಥ, ಉದಾಹರಣೆ ಮತ್ತು ಪ್ರದೇಶದ ಮಾಹಿತಿ. ನಂತರ ಎರಡು ವಿಭಿನ್ನ ಜೀವನಸಂದರ್ಭಗಳಿವೆ. ಆ ಎರಡೂ ಸಂದರ್ಭಗಳನ್ನು ಕನ್ನಡ ಮತ್ತು ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ಓದಬಹುದು.

ಹೀಗಾಗಿ ಗಾದೆಯನ್ನು ಕಂಠಪಾಠ ಮಾಡುವುದಷ್ಟೇ ಅಲ್ಲ, ಅದನ್ನು ಎಲ್ಲಿ ಬಳಸಬಹುದು ಎಂಬುದನ್ನೂ ತಿಳಿದುಕೊಳ್ಳಬಹುದು.

[“ವಿವರಣೆ ಕೇಳಿ” ಒತ್ತಿ. ಸಿದ್ಧವಾದ ಧ್ವನಿಯನ್ನು ಸುಮಾರು 5–8 ಸೆಕೆಂಡ್ ಕೇಳಿಸಿ; ನಂತರ pause ಮಾಡಿ.]

**“ವಿವರಣೆ ಕೇಳಿ”** ಗುಂಡಿಯಿಂದ ಕನ್ನಡದಲ್ಲಿ ಗಾದೆಯ ವಿವರಣೆಯನ್ನು ಕೇಳಬಹುದು. ಧ್ವನಿಯನ್ನು ನಿಲ್ಲಿಸುವ ಮತ್ತು ಮುಂದುವರಿಸುವ ನಿಯಂತ್ರಣಗಳೂ ಇವೆ. ಮೈಕ್ ಮೂಲಕ ಸಂದರ್ಭವನ್ನು ನೀಡುವ ಆಯ್ಕೆಯನ್ನೂ ಸೇರಿಸಿದ್ದೇವೆ. ಪ್ರಸ್ತುತ ಧ್ವನಿ ಇನ್‌ಪುಟ್ ಇಂಗ್ಲಿಷ್‌ಗೆ ಹೊಂದಿಸಲಾಗಿದೆ; ಕನ್ನಡ ಧ್ವನಿ ಗುರುತಿಸುವಿಕೆಯ ನಿಖರತೆ ಇನ್ನೂ ಸುಧಾರಿಸಬೇಕಿದೆ.

## 2:00–2:40 · ಗಾದೆ ನಿಘಂಟು

[Dictionary ಪುಟ ತೆರೆಯಿರಿ. Theme ಆಯ್ದು, Subcategory ತೋರಿಸಿ.]

ಸಂಭಾಷಣೆಯ ಜೊತೆಗೆ ಪ್ರತ್ಯೇಕ **ಗಾದೆ ನಿಘಂಟು** ಇದೆ. ಇಲ್ಲಿ ಎಲ್ಲ 200 ಅನುಮೋದಿತ ಗಾದೆಗಳನ್ನು ಹುಡುಕಿ ಓದಬಹುದು.

ನಾವು ಆರು ಮುಖ್ಯ ವಿಷಯಗಳನ್ನು ಬಳಸಿದ್ದೇವೆ: **ಹಣ, ಕೆಲಸ, ಅಧ್ಯಯನ, ಕುಟುಂಬ, ಸ್ನೇಹಿತರು ಮತ್ತು ವ್ಯಕ್ತಿತ್ವ.** ಮೂಲ categoryಯನ್ನು ಬದಲಾಯಿಸದೆ ಉಪವರ್ಗವಾಗಿ ಉಳಿಸಿದ್ದೇವೆ.

[ಒಂದು ಗಾದೆ ತೆರೆಯಿರಿ; source ಮತ್ತು ಎರಡು ಸಂದರ್ಭಗಳನ್ನು ತೋರಿಸಿ.]

ನಿಘಂಟಿನಲ್ಲೂ ಅದೇ ದ್ವಿಭಾಷಾ ವಿವರ ಕ್ರಮ ಮತ್ತು ಧ್ವನಿ ವಿವರಣೆ ಲಭ್ಯ. ಹುಡುಕಾಟದ ಪಠ್ಯವನ್ನು ತೆರವುಗೊಳಿಸಲು ಗುಂಡಿ ಇದೆ. ಮೂಲದ ಉಲ್ಲೇಖಗಳನ್ನೂ ದಾಖಲಿಸಿದ್ದೇವೆ.

## 2:40–3:35 · ದತ್ತಾಂಶ ಮತ್ತು ಸಲ್ಲಿಕೆ ಕಡತಗಳು

[VS Codeನಲ್ಲಿ `datasets/submission/gaade.csv`, ನಂತರ `situations.csv` ಮತ್ತು `metadata.csv` ತೋರಿಸಿ. ಕೀಗಳು ಅಥವಾ admin-token ಇರುವ tabs ಪರದೆಯಲ್ಲಿ ತೋರಿಸಬೇಡಿ.]

ನಮ್ಮ ಸ್ಥಳೀಯ ಮತ್ತು hosted ದತ್ತಸಂಚಯಗಳಲ್ಲಿ ಈಗ **200 ಅನುಮೋದಿತ ಗಾದೆಗಳಿವೆ**. ಪ್ರತಿಯೊಂದು ಗಾದೆಗೆ ಎರಡು ಸಂದರ್ಭಗಳಂತೆ **400 ಸಂದರ್ಭಗಳನ್ನು** ಸಿದ್ಧಪಡಿಸಿದ್ದೇವೆ. ಪ್ರತಿಯೊಂದು ಸಂದರ್ಭಕ್ಕೂ ಕನ್ನಡ ಮತ್ತು ಇಂಗ್ಲಿಷ್ ಪಠ್ಯವಿದೆ.

ಸಲ್ಲಿಕೆಗಾಗಿ ಗಾದೆ, ಅರ್ಥ, ಇಂಗ್ಲಿಷ್ ರೂಪಾಂತರ, ಉದಾಹರಣೆ, ಪ್ರದೇಶ ಮತ್ತು ವಿಷಯದ ಕ್ಷೇತ್ರಗಳಿರುವ CSV ಕಡತವನ್ನು ಸಿದ್ಧಪಡಿಸಿದ್ದೇವೆ. ಸಂದರ್ಭಗಳನ್ನು ಪ್ರತ್ಯೇಕ CSVಯಲ್ಲಿ **ಗಾದೆ ಐಡಿ** ಮೂಲಕ ಸಂಬಂಧಿತ ಗಾದೆಗೆ ಜೋಡಿಸಿದ್ದೇವೆ. ಕಡತಗಳ ಎಣಿಕೆ ಮತ್ತು ಸಮಗ್ರತೆಯನ್ನು ಪರಿಶೀಲಿಸುವ validation ದಾಖಲೆಯೂ ಇದೆ.

ಇಲ್ಲಿ ಒಂದು ಮುಖ್ಯ ವ್ಯತ್ಯಾಸವಿದೆ: ಗಾದೆಗಳಿಗೆ ವೆಬ್ ಮೂಲಗಳ ಉಲ್ಲೇಖಗಳಿವೆ; ಸಂದರ್ಭಗಳು ನಾವು ರಚಿಸಿದ ನೈಜ ಜೀವನದಂತಿರುವ ಕಲ್ಪಿತ ಉದಾಹರಣೆಗಳು. ಅನುವಾದಗಳ ಪರಿಶೀಲನಾ ಸ್ಥಿತಿಯನ್ನು metadataಯಲ್ಲಿ ಉಳಿಸಿದ್ದೇವೆ. ಸಲ್ಲಿಕೆ CSVಯ ಪ್ರದೇಶಗಳು ಪ್ರಾಯೋಗಿಕವಾಗಿ ಯಾದೃಚ್ಛಿಕವಾಗಿ ನೀಡಿದ ಜಿಲ್ಲೆಗಳು; ಅವು ನಿಜವಾದ ಸಂಗ್ರಹ ಸ್ಥಳಗಳಲ್ಲ ಎಂಬ ಗುರುತನ್ನೂ ಸ್ಪಷ್ಟವಾಗಿ ನೀಡಿದ್ದೇವೆ.

## 3:35–4:10 · ಕರ್ನಾಟಕದ ಜಿಲ್ಲೆಗಳು ಮತ್ತು ಕೊಡುಗೆ

[Districts ಪುಟದಲ್ಲಿ ಒಂದು ಜಿಲ್ಲೆಯನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ, ಭಾಷೆ ಬದಲಿಸಿ. ನಂತರ Share a proverb ಪುಟ ತೋರಿಸಿ.]

ನಮ್ಮ ಭಾಷಾ ಪರಿಚಯದ ಜೊತೆಗೆ ಕರ್ನಾಟಕದ ಸಂಸ್ಕೃತಿಯ ಪರಿಚಯಕ್ಕೂ **31 ಜಿಲ್ಲೆಗಳ ಸಂವಾದಾತ್ಮಕ ನಕ್ಷೆ** ಸೇರಿಸಿದ್ದೇವೆ. ಜಿಲ್ಲೆಯನ್ನು ಆಯ್ಕೆ ಮಾಡಿದಾಗ ಅದರ ಸ್ಥಳಗಳು, ಆಹಾರ ಮತ್ತು ಇತರೆ ಮಾಹಿತಿಯನ್ನು ಕನ್ನಡ ಅಥವಾ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ನೋಡಬಹುದು.

ಹೊಸ ಗಾದೆಯನ್ನು ಹಂಚಿಕೊಳ್ಳಲು ಪ್ರತ್ಯೇಕ ಪುಟವಿದೆ. ಪಠ್ಯ ಅಥವಾ ಧ್ವನಿಯ ಮೂಲಕ ಕೊಡುಗೆ ನೀಡಬಹುದು. ಹೊಸ ಕೊಡುಗೆ ನೇರವಾಗಿ ಪ್ರಕಟವಾಗುವುದಿಲ್ಲ; ಮೊದಲು ಪರಿಶೀಲನೆಗೆ ಹೋಗುತ್ತದೆ. ಅನುಮೋದನೆಯ ನಂತರವೇ ಸಾಮಾನ್ಯ ಬಳಕೆದಾರರಿಗೆ ಲಭ್ಯವಾಗುತ್ತದೆ.

## 4:10–4:40 · ತಂತ್ರಜ್ಞಾನ ಮತ್ತು ಪರೀಕ್ಷೆ

[ಮುಖಪುಟಕ್ಕೆ ಹಿಂತಿರುಗಿ. ಬೇಕಾದರೆ ಮೂರು hosting ಹೆಸರುಗಳ ಸರಳ slide ತೋರಿಸಿ.]

ಮುಂಭಾಗಕ್ಕೆ **ರಿಯಾಕ್ಟ್**, ಹಿಂಭಾಗಕ್ಕೆ **ಫಾಸ್ಟ್‌ಎಪಿಐ**, hosted ದತ್ತಸಂಚಯಕ್ಕೆ **ಸುಪಾಬೇಸ್** ಬಳಸಿದ್ದೇವೆ. ವೆಬ್‌ಸೈಟ್‌ನ್ನು **ವರ್ಸೆಲ್**, backend ಸೇವೆಯನ್ನು **ರೆಂಡರ್** ಮೂಲಕ ಒದಗಿಸಿದ್ದೇವೆ. API ಕೀಗಳು backendನಲ್ಲಿ ಮಾತ್ರ ಇರುತ್ತವೆ.

ನಾವು ಹೊಸ ಭಾಷಾ ಮಾದರಿಯನ್ನು ತರಬೇತಿಗೊಳಿಸಿಲ್ಲ. ಪೂರ್ವತರಬೇತಿ ಪಡೆದ ಮಾದರಿಗಳು ಮತ್ತು ನಮ್ಮ ಅನುಮೋದಿತ ಗಾದೆಗಳ ಸಂಗ್ರಹವನ್ನು ಬಳಸುತ್ತಿದ್ದೇವೆ. ಇತ್ತೀಚಿನ backend ಪರೀಕ್ಷೆಗಳಲ್ಲಿ **47 ಪರೀಕ್ಷೆಗಳು ಉತ್ತೀರ್ಣವಾಗಿವೆ**; ಒಂದು ಪರಿಸರಾಧಾರಿತ ಪರೀಕ್ಷೆ skip ಆಗಿದೆ. Browser ಮತ್ತು build ಪರಿಶೀಲನೆಗಳನ್ನೂ ನಡೆಸಿದ್ದೇವೆ.

## 4:40–5:00 · ಉಳಿದ ಕೆಲಸ ಮತ್ತು ಸಮಾಪ್ತಿ

[Logo ಮತ್ತು ಧ್ಯೇಯವಾಕ್ಯದೊಂದಿಗೆ ಮುಗಿಸಿ.]

ಮುಂದಿನ ಹಂತದಲ್ಲಿ ಹಿರಿಯರಿಂದ ನೇರ ಸಂಗ್ರಹ, ನಿಜವಾದ ಪ್ರದೇಶದ ಮಾಹಿತಿ, ಒಪ್ಪಿಗೆ ಪತ್ರಗಳು ಮತ್ತು ಪ್ರತಿ ಗಾದೆಯ ಮಾನವ ಧ್ವನಿ ಓದನ್ನು ಪೂರ್ಣಗೊಳಿಸಬೇಕಿದೆ. ಸದ್ಯದ 24 MP3 ಕಡತಗಳು ಅಗತ್ಯವಾದ 16 ಕಿಲೋಹರ್ಟ್ಸ್ mono WAV ರೂಪದಲ್ಲಿಲ್ಲ. ಕನ್ನಡ ಧ್ವನಿ ಗುರುತಿಸುವಿಕೆ ಮತ್ತು ಭಾಷಾ ಪರಿಶೀಲನೆಯನ್ನೂ ಸುಧಾರಿಸಬೇಕಿದೆ.

ಕನ್ನಡ ಗಾದೆಗಳನ್ನು ಸಂದರ್ಭದೊಂದಿಗೆ ಅರಿತು ಬಳಸಲು ನೆರವಾಗುವುದೇ **ಗಾದಾಮೃತದ** ಉದ್ದೇಶ.

**ಧನ್ಯವಾದಗಳು!**

## ಚಿತ್ರೀಕರಣದ ಮೊದಲು

- ಸುಮಾರು 5 ನಿಮಿಷಕ್ಕೆ ಹೊಂದಲು ಒಂದು timed rehearsal ಮಾಡಿ; ಹುಡುಕಾಟ ಅಥವಾ ಧ್ವನಿಗೆ ಹೆಚ್ಚು ಸಮಯ ಹಿಡಿದರೆ ಪುಟ ಬದಲಾವಣೆಯ ವಿರಾಮಗಳನ್ನು ಕಡಿಮೆ ಮಾಡಿ.
- Live website, dictionary, district map ಮತ್ತು CSVಗಳನ್ನು ಮೊದಲೇ ತೆರೆಯಿರಿ. Backend ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತಿದೆಯೇ ಪರಿಶೀಲಿಸಿ.
- ಹುಡುಕಾಟಕ್ಕೆ ಮೇಲಿನ ಸಂದರ್ಭ ಸಿದ್ಧವಿರಲಿ. ಉತ್ತರವನ್ನು ಮುಂಚಿತವಾಗಿ ನಿಶ್ಚಯಿಸಿ ಹೇಳಬೇಡಿ; ಬಂದಿರುವ ಹೊಂದಾಣಿಕೆಯನ್ನು ತೋರಿಸಿ.
- ಧ್ವನಿ playback ಅನ್ನು ಮೊದಲೇ ಪರಿಶೀಲಿಸಿ; API quota ಅಥವಾ network ವಿಳಂಬದಿಂದ demo ನಿಲ್ಲದಂತೆ ನೋಡಿಕೊಳ್ಳಿ.
- `.env`, `.env.cloud`, API keys, password, admin-token ಮತ್ತು ಖಾಸಗಿ approval backups ಪರದೆಯಲ್ಲಿ ಕಾಣಿಸದಂತೆ ಇಡಿ.
- “200 ಮಾನವ recordings”, “ಪ್ರದೇಶಗಳು verified”, “100% accuracy”, “ಹಿರಿಯರಿಂದ ಸಂಗ್ರಹಿಸಿದ corpus” ಅಥವಾ “ನಾವು ಮಾದರಿಯನ್ನು train ಮಾಡಿದ್ದೇವೆ” ಎಂದು ಹೇಳಬೇಡಿ; ಅವು ಈಗಿನ ಸಾಕ್ಷಿಗೆ ಹೊಂದುವುದಿಲ್ಲ.
