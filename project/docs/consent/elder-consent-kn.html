ಕನ್ನಡ ಗಾದೆ, ಅರ್ಥ ಮತ್ತು ಬಳಕೆಯನ್ನು ಜನರಿಗೆ ಪರಿಚಯಿಸುವುದು ಯೋಜನೆಯ ಉದ್ದೇಶ. ಪಾಲ್ಗೊಳ್ಳುವುದು ನಿಮ್ಮ ಇಚ್ಛೆ. ಪ್ರಶ್ನೆ ಕೇಳಬಹುದು, ಉತ್ತರಿಸದಿರಬಹುದು ಅಥವಾ ನಿಲ್ಲಿಸಬಹುದು; ನಿರಾಕರಿಸಿದರೂ ತೊಂದರೆ ಇಲ್ಲ. ಧ್ವನಿ ದಾಖಲಿಸುವ ಮೊದಲು ಎರಡೂ ಪುಟಗಳನ್ನು ವಿವರಿಸಿ, ಆಯ್ಕೆ ತುಂಬಿ, ಸಹಿ ಪಡೆಯಿರಿ.

ನನ್ನ ಆಯ್ಕೆಗಳು — ಪ್ರತಿ ಸಾಲಿನಲ್ಲಿ ಒಂದನ್ನು ಗುರುತಿಸಿ

ಗುರುತು ಇಲ್ಲದ ಸಾಲಿಗೆ ಅನುಮತಿ ನೀಡಿಲ್ಲ ಎಂದು ಪರಿಗಣಿಸಿ. ಒಂದು ಅನುಮತಿಯು ಉಳಿದ ಅನುಮತಿಗಳಿಗೆ ಅನ್ವಯಿಸುವುದಿಲ್ಲ.

ನಾನು ಅನುಮತಿಸುವ ಬಳಕೆ / Permissionಹೌದು / Yesಇಲ್ಲ / No
ನಾನು ಹೇಳುವ ಗಾದೆ, ನನ್ನ ಅರ್ಥ ವಿವರಣೆ ಮತ್ತು ಉದಾಹರಣೆಯನ್ನು ಬರೆದು, ಪರಿಶೀಲನೆಗಾಗಿ ತಂಡದೊಳಗೆ ಇಡುವುದು.
ಅನುಮೋದಿತ ಪಠ್ಯವನ್ನು ಯೋಜನೆಯ ಜಾಲತಾಣ, ಹ್ಯಾಕಥಾನ್ ಪ್ರದರ್ಶನ ಮತ್ತು ಸಲ್ಲಿಕೆಯಲ್ಲಿ ಹಂಚಿಕೊಳ್ಳುವುದು.
ನನ್ನ ಧ್ವನಿಯನ್ನು ದಾಖಲಿಸಿ ಖಾಸಗಿಯಾಗಿ ಇಡುವುದು.
ನನ್ನ ಧ್ವನಿ ಓದನ್ನು ಜಾಲತಾಣದಲ್ಲಿ ಕೇಳಿಸಲು ಮತ್ತು ಹ್ಯಾಕಥಾನ್ ಪ್ರದರ್ಶನ / ಸಲ್ಲಿಕೆಯಲ್ಲಿ ಬಳಸುವುದು.
ಧ್ವನಿಯನ್ನು ಪಠ್ಯಕ್ಕೆ ಬದಲಿಸಲು Groq ಸೇವೆಗೆ ನನ್ನ ಧ್ವನಿ ಕಡತವನ್ನು ಕಳುಹಿಸುವುದು.
ಅನುವಾದ / ವಿವರಣೆಯ ನೆರವಿಗಾಗಿ ನನ್ನ ಕೊಡುಗೆಯ ಪಠ್ಯವನ್ನು Gemini ಅಥವಾ Groqಗೆ ಕಳುಹಿಸುವುದು.

ಧ್ವನಿ ಅಥವಾ ಪಠ್ಯವನ್ನು ಹೊರಗಿನ ಸೇವೆಗೆ ಕಳುಹಿಸಲು “ಹೌದು” ಎಂದರೆ ಅದು ಆ ಸೇವೆಯಲ್ಲೂ ಸಂಸ್ಕರಿಸಲ್ಪಡುತ್ತದೆ; ಅವರ ನಿಯಮಗಳು ಅನ್ವಯಿಸುತ್ತವೆ. ಈ ಒಪ್ಪಿಗೆ ಪತ್ರ, ಸಹಿ ಅಥವಾ ವೈಯಕ್ತಿಕ ಸಂಪರ್ಕ ವಿವರಗಳನ್ನು AI ಸೇವೆಗೆ ಕಳುಹಿಸಬಾರದು. ಧ್ವನಿಯಿಂದ ನನ್ನನ್ನು ಗುರುತಿಸುವ ಸಾಧ್ಯತೆ ಇದೆ; ಬೇರೆ ಹೆಸರು ಬಳಸಿದರೂ ಧ್ವನಿ ಅನಾಮಧೇಯವಾಗುವುದಿಲ್ಲ.

ಮುಂದಿನ ಪುಟದಲ್ಲಿ ಮುಕ್ತ ಹಂಚಿಕೆ, ಹೆಸರಿನ ಆಯ್ಕೆ ಮತ್ತು ಸಹಿ ಇದೆ. ಎರಡೂ ಪುಟಗಳನ್ನು ಜೊತೆಯಾಗಿ ಇಡಿ.

ತಂಡವನ್ನು ಸಂಪರ್ಕಿಸಿ Consent ID ಹೇಳಿ ತಿದ್ದುಪಡಿ, ಪ್ರಕಟಣೆ ನಿಲ್ಲಿಸಲು ಅಥವಾ ತಂಡದ ನಿಯಂತ್ರಣದಲ್ಲಿರುವ ವೈಯಕ್ತಿಕ ದತ್ತಾಂಶವನ್ನು ತೆಗೆದುಹಾಕಲು ಕೋರಬಹುದು. ಪ್ರಕಟಣೆಗೆ ಮುನ್ನ ಹಂಚಿಕೆಯನ್ನು ನಿಲ್ಲಿಸಬಹುದು. ಮುಕ್ತ ಪ್ರತಿಗಳಿಗೆ ಮೇಲಿನ ಪರವಾನಗಿ ಮಿತಿಗಳು ಅನ್ವಯಿಸುತ್ತವೆ. ಈ ಪತ್ರ ಕಾನೂನುಬದ್ಧ ಹಕ್ಕನ್ನು ತ್ಯಜಿಸಲು ಕೇಳುವುದಿಲ್ಲ.
