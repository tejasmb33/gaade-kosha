# ಹಿರಿಯರ ಒಪ್ಪಿಗೆ ಪತ್ರ ಬಳಸುವುದು

`elder-consent-kn.pdf` ಎರಡು ಪುಟಗಳ ಮುದ್ರಣ ಪ್ರತಿಯಾಗಿದೆ. ತಿದ್ದುಪಡಿಗೆ `elder-consent-kn.md`; browserನಲ್ಲಿ ಮುದ್ರಿಸಲು `elder-consent-kn.html` ಬಳಸಿ. ಇದು ಖಾಲಿ ಯೋಜನಾ ನಮೂನೆ; ಸಹಿ ಮಾಡಿದ ದಾಖಲೆ ಅಥವಾ ಹಿಂದಿನ ಕೊಡುಗೆಗಳಿಗೆ ಈಗಾಗಲೇ ಒಪ್ಪಿಗೆ ಇದೆ ಎಂಬ ಸಾಕ್ಷಿಯಲ್ಲ.

## ಸಂಗ್ರಹಿಸುವ ಮೊದಲು

1. ತಂಡ / ಸಂಸ್ಥೆ, ಹಿರಿಯರು ಸುಲಭವಾಗಿ ಸಂಪರ್ಕಿಸಬಹುದಾದ ಇಮೇಲ್ ಅಥವಾ ಸಂಪರ್ಕ, ಖಾಸಗಿ ಸಂಗ್ರಹ ಅವಧಿ ಮತ್ತು Consent ID ತುಂಬಿ. ಅವಧಿಯನ್ನು ತಂಡವು ತನ್ನ ನಿಜವಾದ ನೀತಿಯಂತೆ ನಿರ್ಧರಿಸಬೇಕು; ಖಾಲಿ ಬಿಡಬೇಡಿ.
2. ಎರಡೂ ಪುಟಗಳನ್ನು ಹಿರಿಯರಿಗೆ ಅರ್ಥವಾಗುವ ಭಾಷೆಯಲ್ಲಿ ಓದಿ ವಿವರಿಸಿ. ಧ್ವನಿ ದಾಖಲಿಸುವ ಮೊದಲು ಅವರ ಆಯ್ಕೆಗಳನ್ನು ತುಂಬಿ, ಸಹಿ / ಹೆಬ್ಬೆರಳ ಗುರುತು ಪಡೆಯಿರಿ. ಓದಿ ವಿವರಿಸಿದರೆ ಸಾಕ್ಷಿಯ ವಿವರ ತುಂಬಿ. ಒಪ್ಪಿಗೆ ಪಡೆಯಲು ಹಿಂದಿನ ದಿನಾಂಕ ಹಾಕಬೇಡಿ.
3. ಪ್ರತಿ ಪ್ರಶ್ನೆಗೆ ಹೌದು ಅಥವಾ ಇಲ್ಲ ಗುರುತಿಸುವಂತೆ ಬಿಡಿ. ಗುರುತು ಇಲ್ಲದಿರುವುದನ್ನು ಅನುಮತಿಯಾಗಿ ಬಳಸಬೇಡಿ. ಪಠ್ಯವನ್ನು ಹಂಚಲು ಒಪ್ಪಿದ್ದರೆ ಧ್ವನಿ ಅಥವಾ cloud processingಗೂ ಒಪ್ಪಿದ್ದಾರೆ ಎಂದು ಊಹಿಸಬೇಡಿ.
4. “Publish text” ಇಲ್ಲದೆ text open release, ಅಥವಾ “Record/share voice” ಇಲ್ಲದೆ audio open release ಗುರುತಿಸಿದ್ದರೆ ಗೊಂದಲ ನಿವಾರಿಸಿ, ಆಯ್ಕೆಗಳನ್ನು ಅವರಿಂದ ಮತ್ತೆ ದೃಢಪಡಿಸಿಕೊಳ್ಳಿ. ಮುಕ್ತ ಪರವಾನಗಿ ಹಂಚಿಕೆಗೆ ಸಾಮಾನ್ಯ ಪ್ರಕಟಣೆ ಮತ್ತು ಆ ನಿರ್ದಿಷ್ಟ CC BY ಆಯ್ಕೆ ಎರಡೂ ಹೌದು ಆಗಿರಬೇಕು.
5. ಸಂಬಂಧಿತ ಪ್ರತಿಯೊಂದು ಗಾದೆಯ ID, audio filename ಮತ್ತು Consent IDಯನ್ನು ಖಾಸಗಿ registerನಲ್ಲಿ ಜೋಡಿಸಿ. ಹಲವಾರು ಗಾದೆಗಳಿದ್ದರೆ ಪ್ರತ್ಯೇಕ ID ಪಟ್ಟಿಯನ್ನು ಲಗತ್ತಿಸಿ, ಲಗತ್ತಿಗೆ ಸಹಿ / initials ಪಡೆಯಿರಿ. ಹೇಳದ ಜಿಲ್ಲೆ ಅಥವಾ ಮೂಲವನ್ನು ಊಹಿಸಿ ತುಂಬಬೇಡಿ.
6. ಸಾರ್ವಜನಿಕ ಹೆಸರು ಆಯ್ಕೆಯನ್ನು ದೃಢಪಡಿಸಿ; ಹೆಸರನ್ನು ಹಂಚಲು ಆಯ್ಕೆ ಮಾಡದಿದ್ದರೆ contributor code ಬಳಸಿ. ರೆಕಾರ್ಡಿಂಗ್‌ನಲ್ಲೂ ಹೆಸರು, ಮನೆ ವಿಳಾಸ ಅಥವಾ ದೂರವಾಣಿ ಸಂಖ್ಯೆ ಹೇಳದಂತೆ ಮೊದಲೇ ತಿಳಿಸಿ.
7. ಕೊಡುಗೆದಾರರಿಗೆ ಎರಡೂ ಪುಟಗಳ ಪ್ರತಿಯನ್ನು ನೀಡಿ. ಹೊಸ ಕೊಡುಗೆ ಇನ್ನೂ pending; consent ಇದ್ದುದರಿಂದ ಮಾತ್ರ ಅದರ ಅರ್ಥ ಅಥವಾ ಸಾಂಸ್ಕೃತಿಕ ನಿಖರತೆ verified ಆಗುವುದಿಲ್ಲ.

## ಖಾಸಗಿ ಸಂಗ್ರಹ ಮತ್ತು ಬಳಕೆ

- ಖಾಲಿ ನಮೂನೆಯನ್ನು `docs/consent/`ನಲ್ಲಿ ಇಡಬಹುದು. **ಸಹಿ ಮಾಡಿದ ಪ್ರತಿಗಳು, ಹೆಸರುಗಳು, ಹೆಬ್ಬೆರಳ ಗುರುತುಗಳು ಮತ್ತು ಸಂಪರ್ಕ ವಿವರಗಳನ್ನು GitHub ಅಥವಾ ಸಾರ್ವಜನಿಕ datasetಗೆ ಸೇರಿಸಬೇಡಿ.**
- ಸಂಗ್ರಹಿಸಿದ ದಾಖಲೆಗಳನ್ನು ಪ್ರವೇಶ ಮಿತಿಯಿರುವ ಸಂಗ್ರಹದಲ್ಲಿ ಇಡಿ; ಸ್ಥಳೀಯವಾಗಿ ಇಡಬೇಕಾದರೆ Git-ignored `project/data/consent/` ಬಳಸಬಹುದು. Backup ಮತ್ತು ತಂಡದ ಪ್ರವೇಶ ನೀತಿ ನಿಗದಿ ಮಾಡಿ.
- ಸಂಘಟಕರಿಗೆ consent ಸಾಕ್ಷಿ ಬೇಕಾದರೆ ಅವರ restricted submission ವಿಧಾನ ಬಳಸಿ. ಸಾರ್ವಜನಿಕ metadataಯಲ್ಲಿ Consent ID / contributor code ಮತ್ತು ಅನುಮತಿಸಿದ ಬಳಕೆಯ ಸ್ಥಿತಿ ಸಾಕು; ಸಹಿ scan ಬೇಡ.
- Cloud processingಗೆ “ಇಲ್ಲ” ಇದ್ದರೆ ತಂಡ ಅನುಮೋದಿತ ಸ್ಥಳೀಯ ವಿಧಾನ ಅಥವಾ ಕೈಯಾರೆ ಲಿಪ್ಯಂತರ ಬಳಸಿ. ಈಗಿರುವ web app ಈ ಕಾಗದದ ಆಯ್ಕೆಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಜಾರಿಗೊಳಿಸುವುದಿಲ್ಲ; operator ಅವುಗಳನ್ನು ಪರಿಶೀಲಿಸಬೇಕು.
- ತಿದ್ದುಪಡಿ / ಹಿಂತೆಗೆದುಕೊಳ್ಳುವ ವಿನಂತಿ, ದಿನಾಂಕ ಮತ್ತು ಕೈಗೊಂಡ ಕ್ರಮವನ್ನು ಖಾಸಗಿಯಾಗಿ ದಾಖಲಿಸಿ. ಹೊಸ ಸಂಗ್ರಹ ಅಥವಾ ಬಳಕೆಗೆ ಹಳೆಯ ಪತ್ರದಲ್ಲಿ ಇಲ್ಲದ ಅನುಮತಿ ಬೇಕಾದರೆ ಮತ್ತೆ ವಿವರಿಸಿ, ಒಪ್ಪಿಗೆ ಪಡೆಯಿರಿ.
- ಸ್ಪೀಕರ್ ಮತ್ತು ಬರಹಗಾರ ಬೇರೆ ವ್ಯಕ್ತಿಗಳಾದರೆ ಅವರವರ ಕೊಡುಗೆಗಾಗಿ ಪ್ರತ್ಯೇಕ ಒಪ್ಪಿಗೆ ಪಡೆಯಿರಿ. 18 ವರ್ಷದೊಳಗಿನವರಿಗೆ ಈ adult form ಬಳಸಬೇಡಿ.

## ಈ ನಮೂನೆಯ ವ್ಯಾಪ್ತಿ

ಇದು ಗಾದಾಮೃತ ತಂಡಕ್ಕೆ ಹೊಂದಿಸಿಕೊಳ್ಳಲು ಸಿದ್ಧಪಡಿಸಿದ consent draft. ಖಾಲಿ contact/retention ಕ್ಷೇತ್ರಗಳು ಮತ್ತು ನಿಜವಾದ processing / storage policy ಹೊಂದಿಕೆಯನ್ನು ಸಂಗ್ರಹಕ್ಕೂ ಮೊದಲು ಪರಿಶೀಲಿಸಿ. ಇದು ಕಾನೂನು ಪಾಲನೆಯ ಪ್ರಮಾಣಪತ್ರವಲ್ಲ. ಫೋಟೊ, ವೀಡಿಯೊ, ಧ್ವನಿ ಅನುಕರಣೆ ಅಥವಾ ಬೇರೆಯವರ ಕೃತಿಗೆ ಹಕ್ಕು ಇದೆ ಎಂಬ ಘೋಷಣೆಗೆ ಇದನ್ನು ಬಳಸಬೇಡಿ.

CC BY ಅನುಮತಿ ದಾನಿಯ ಹಕ್ಕಿರುವ ವಿಷಯಕ್ಕೆ ಮಾತ್ರ ಅನ್ವಯಿಸುತ್ತದೆ. ಈ ಮೂರು ಸ್ಥಿತಿಗಳನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ದಾಖಲಿಸಿ: (1) ಯೋಜನೆಯಲ್ಲಿ ಬಳಸಲು consent, (2) open-license ಆಯ್ಕೆ, (3) ಭಾಷಾ / ಸಾಂಸ್ಕೃತಿಕ ಪರಿಶೀಲನೆ. ಯೋಜನೆಯ ಎಲ್ಲಾ ಪ್ರಸ್ತುತ MP3ಗಳು ಅಥವಾ dataset ಈ ಪರವಾನಗಿಗೆ ಅರ್ಹವೆಂದು ಈ ಖಾಲಿ ಪತ್ರ ಸೂಚಿಸುವುದಿಲ್ಲ.
