# ಗಾದಾಮೃತ — ಸಲ್ಲಿಕೆಗಾಗಿ ಸಿದ್ಧಪಡಿಸಿದ ಪಠ್ಯ ದತ್ತಾಂಶ

**ಪ್ರಸ್ತುತ ಸ್ಥಿತಿ: 19 ನವೆಂಬರ್ 2026.** ಸ್ಥಳೀಯವಾಗಿ ಅನುಮೋದಿತ 200 ಗಾದೆಗಳಿಂದ ಈ ಕಡತಗಳನ್ನು ಸಿದ್ಧಪಡಿಸಲಾಗಿದೆ. ಇಲ್ಲಿ ಪಠ್ಯ CSVಗಳ ಜೊತೆಗೆ `audio/`ಯಲ್ಲಿ 24 MP3 ಕಡತಗಳಿವೆ; ಇದು ಪೂರ್ಣ ಹ್ಯಾಕಥಾನ್ ಸಲ್ಲಿಕೆ ಪ್ಯಾಕೇಜ್ ಅಲ್ಲ.

## ಕಡತಗಳು ಮತ್ತು ಕ್ಷೇತ್ರಗಳು

| ಕಡತ | ಸಾಲುಗಳು | ವಿವರ |
|---|---:|---|
| `gaade.csv` | 200 | ಗಾದೆ, ಅರ್ಥ, ಇಂಗ್ಲಿಷ್ ರೂಪಾಂತರ, ಉದಾಹರಣೆ, ಪ್ರದೇಶ ಮತ್ತು ವಿಷಯ |
| `situations.csv` | 400 | ಪ್ರತಿ ಗಾದೆಗೆ ಎರಡು ವಿಭಿನ್ನ ಸಂದರ್ಭಗಳು; ಪ್ರತಿಯೊಂದು ಕನ್ನಡ ಮತ್ತು ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ |
| `metadata.csv` | 200 | ಮೂಲ, ಮೂಲ category, ಅನುಮೋದನಾ/ಅನುವಾದ ಸ್ಥಿತಿ ಮತ್ತು synthetic ಪ್ರದೇಶ ಗುರುತು |
| `validation.json` | — | ಎಣಿಕೆಗಳು, ವಿಷಯವಾರು ಹಂಚಿಕೆ ಮತ್ತು CSVಗಳ SHA-256 ಮೌಲ್ಯಗಳು |

`gaade.csv`ಯ ಕ್ಷೇತ್ರಗಳು:

```text
gaade_id, gaade, meaning, English, example, region, theme, region_status
```

- `gaade_id`: ಸ್ಥಳೀಯ databaseನ ಸ್ಥಿರ ಗುರುತು; ಸಂದರ್ಭಗಳನ್ನು ಜೋಡಿಸಲು ಬಳಸಿ.
- `gaade`: ಮೂಲ ಕನ್ನಡ ಗಾದೆ.
- `meaning`: ಕನ್ನಡದಲ್ಲಿ ಭಾವಾರ್ಥ.
- `English`: ಗಾದೆಯ ಇಂಗ್ಲಿಷ್ ರೂಪಾಂತರ. ಇದು ಪ್ರಚಲಿತ ಇಂಗ್ಲಿಷ್ ಗಾದೆಗೆ ಸಮಾನವೆಂದು ದೃಢಪಡಿಸಿಲ್ಲ.
- `example`: ಕನ್ನಡ ಬಳಕೆಯ ಉದಾಹರಣೆ.
- `region`: ಬಳಕೆದಾರರ ಕೋರಿಕೆಯಂತೆ ಹಾಕಿರುವ **ಯಾದೃಚ್ಛಿಕ ಕರ್ನಾಟಕ ಜಿಲ್ಲೆ**; ನಿಜವಾದ ಮೂಲ ಅಥವಾ ಸಂಗ್ರಹ ಸ್ಥಳವಲ್ಲ.
- `theme`: `money`, `work`, `study`, `family`, `friends`, `character`ಗಳಲ್ಲಿ ಒಂದು.
- `region_status`: ಎಲ್ಲ 200 ಸಾಲುಗಳಲ್ಲೂ `SYNTHETIC_RANDOM_DEMO_NOT_PROVENANCE`.

`situations.csv`ಯ ಕ್ಷೇತ್ರಗಳು:

```text
situation_id, gaade_id, situation_kn, situation_en, synthetic, review_status
```

ಒಂದು ಸಾಲು ಎಂದರೆ ಒಂದೇ ಸಂದರ್ಭದ ಎರಡು ಭಾಷಾ ರೂಪಗಳು. ಪ್ರತಿ `gaade_id`ಗೆ ನಿಖರವಾಗಿ ಎರಡು ಸಾಲುಗಳಿವೆ. `situations.gaade_id` ಅನ್ನು `gaade.gaade_id`ಗೆ ಜೋಡಿಸಿ. ಸಂದರ್ಭಗಳು ನೈಜ ಜೀವನಕ್ಕೆ ಹೊಂದುವಂತೆ ರಚಿಸಿದ ಕಲ್ಪಿತ ಉದಾಹರಣೆಗಳು; ಸಂಗ್ರಹಿಸಿದ ನಿಜಘಟನೆಗಳಲ್ಲ. ಆದ್ದರಿಂದ `synthetic=true` ಮತ್ತು `review_status=MACHINE_TRANSLATION_DRAFT` ಗುರುತುಗಳನ್ನು ಉಳಿಸಲಾಗಿದೆ.

ಮೂಲ backend categories ಬದಲಾಗಿಲ್ಲ; ಅವು `metadata.csv`ಯಲ್ಲಿ ಪ್ರತ್ಯೇಕವಾಗಿ ಉಳಿದಿವೆ.

## ಸೇರಿಸಿರುವ audio ಕಡತಗಳು

`audio/`ಯಲ್ಲಿ 24 MP3 ಕಡತಗಳಿವೆ. FFprobe ಪರಿಶೀಲನೆಯಲ್ಲಿ ಎಲ್ಲವೂ 48 kHz stereo ಎಂದು ಕಂಡುಬಂದಿವೆ; ಅವು ಅಗತ್ಯವಾದ 16 kHz mono WAV ರೂಪದಲ್ಲಿಲ್ಲ. ಇವು ಯಾವ speakerನ ಓದುಗಳು ಅಥವಾ generated audio ಎಂಬುದನ್ನು ಇಲ್ಲಿ ದೃಢಪಡಿಸಿಲ್ಲ. `gaade_id` ಆಧಾರಿತ audio manifest, transcript matching, consent ಮತ್ತು pronunciation review ಇನ್ನೂ ದೃಢಪಟ್ಟಿಲ್ಲ. ಇವುಗಳನ್ನು 200 ಪರಿಶೀಲಿತ ಮಾನವ readings ಎಂದು ಎಣಿಸಬೇಡಿ.

## ಪರಿಶೀಲನೆ ಮತ್ತು ಮೂಲದ ಬಗ್ಗೆ ಮುಖ್ಯ ಮಾಹಿತಿ

ಈ 200 ಗಾದೆಗಳನ್ನು ಯೋಜನೆಯ ಬಳಕೆದಾರರು ಸ್ಪಷ್ಟವಾಗಿ ಅನುಮೋದಿಸಿದ್ದಾರೆ. ಆದರೆ ಅರ್ಥಗಳು, ಅನುವಾದಗಳು ಮತ್ತು ಸಂದರ್ಭಗಳಿಗೆ ಸ್ವತಂತ್ರ ಕನ್ನಡ/ಸಾಂಸ್ಕೃತಿಕ ಪರಿಶೀಲನೆ ಇನ್ನೂ ಅಗತ್ಯ. ಸುಲಭ ಓದಿಗಾಗಿ ಮುಖ್ಯ ಪಠ್ಯದ draft ಮುನ್ನುಡಿಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ; ಅದರ ಪರಿಶೀಲನಾ ಸ್ಥಿತಿಯನ್ನು metadataಯಲ್ಲಿ ಉಳಿಸಲಾಗಿದೆ.

**ಎಲ್ಲ 200 ಪ್ರದೇಶ ಮೌಲ್ಯಗಳು synthetic. ನಿಜವಾದ ಪ್ರದೇಶ ಮಾಹಿತಿ ಇನ್ನೂ ದಾಖಲಾಗಿಲ್ಲ.** ಇವುಗಳನ್ನು ಗಾದೆಯ ಪ್ರಾದೇಶಿಕ ಮೂಲ, ಉಪಭಾಷೆ ಅಥವಾ ಹಿರಿಯರಿಂದ ಸಂಗ್ರಹಿಸಿದ ಸ್ಥಳಗಳೆಂದು ಸಲ್ಲಿಸಬೇಡಿ. Random ಪ್ರದೇಶಗಳನ್ನು CSVಗೆ ಸೇರಿಸಿದಾಗ backend database ಪ್ರದೇಶ ಕ್ಷೇತ್ರಗಳು ಬದಲಾಗಿಲ್ಲ.

ವೆಬ್ URLಗಳು ಗಾದೆಯ ಉಲ್ಲೇಖಗಳು ಮಾತ್ರ; ಹೊಸ ಸಂದರ್ಭಗಳು ಆ ಪುಟಗಳಿಂದ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ ಎಂಬ ಅರ್ಥವಲ್ಲ. ಈ ಸಂಗ್ರಹವು ಹಿರಿಯರಿಂದ ನೇರವಾಗಿ ಸಂಗ್ರಹಿಸಿದ corpus ಎಂದು ಸ್ಥಾಪಿತವಾಗಿಲ್ಲ.

ಇಲ್ಲಿ 16 kHz mono WAV ಮಾನವ ಓದುಗಳು, signed speaker/writer consent, peer-review ಸಾಕ್ಷಿ ಅಥವಾ ಮರುಬಳಕೆ ಪರವಾನಗಿ ಅನುಮತಿಗಳು ಸೇರಿಲ್ಲ. ಅವು ಪೂರ್ಣಗೊಂಡಿವೆ ಎಂದು ಈ CSVಗಳು ಸೂಚಿಸುವುದಿಲ್ಲ. API ಕೀಗಳು, admin token, ಖಾಸಗಿ recordings ಅಥವಾ ಸಂಪರ್ಕ ವಿವರಗಳನ್ನು ಸೇರಿಸಿಲ್ಲ.

## ರೂಪ ಮತ್ತು ಪರಿಶೀಲನೆ

CSVಗಳು **UTF-8 with BOM** ರೂಪದಲ್ಲಿವೆ; spreadsheetಗಳಲ್ಲಿ ಕನ್ನಡ ಓದಲು ಅನುಕೂಲವಾಗುತ್ತದೆ. ಪರಿಶೀಲನೆಯಾಗಿರುವ ಅಂಶಗಳು:

- 200 ವಿಶಿಷ್ಟ `gaade_id`ಗಳು.
- 400 ಸಂದರ್ಭಗಳು; ಪ್ರತಿ ಗಾದೆಗೆ ಎರಡು ಸಂಪರ್ಕಗಳು.
- ಎಲ್ಲ ಸಂದರ್ಭಗಳಿಗೆ ಕನ್ನಡ ಮತ್ತು ಇಂಗ್ಲಿಷ್ ಪಠ್ಯ.
- Random ಪ್ರದೇಶಗಳಿಗೆ ಸ್ಪಷ್ಟ synthetic ಗುರುತು.
- `validation.json`ನ CSV hash ಮೌಲ್ಯಗಳ ಹೊಂದಾಣಿಕೆ.

ಈ ತಾಂತ್ರಿಕ ಪರಿಶೀಲನೆ ಅರ್ಥದ ಸಾಂಸ್ಕೃತಿಕ ನಿಖರತೆಗೆ ಮಾನವ ಅನುಮೋದನೆ ನೀಡುವುದಿಲ್ಲ. `metadata.csv`ಯನ್ನು ಮುಖ್ಯ ದತ್ತಾಂಶದ ಜೊತೆಗೆ ಉಳಿಸಿ.

## ಪುನಃ export ಮಾಡುವುದು

Repository ಮೂಲ directoryಯಿಂದ:

```sh
project/.venv/bin/python project/scripts/export_submission.py
```

ಈ command cloud ಕರೆ ಮಾಡುವುದಿಲ್ಲ; source database ಅನ್ನು read-only ಆಗಿ ಓದುತ್ತದೆ. Import, approve ಅಥವಾ upload ಮಾಡುವುದಿಲ್ಲ.

**ಪುನಃ export ಮಾಡಿದರೆ ಕೈಯಾರೆ ಹಾಕಿದ random ಪ್ರದೇಶಗಳು ತೆಗೆದುಹೋಗುತ್ತವೆ.** Backendನಲ್ಲಿ ಇರುವ ನಿಜವಾದ ಪ್ರದೇಶ ಮೌಲ್ಯಗಳು ಬರುತ್ತವೆ; ಈಗ ಅವು ಖಾಲಿ. ಮೂಲ labeled/evaluation ಕಡತಗಳು ಬದಲಾಗುವುದಿಲ್ಲ.
