This product is a modified version of Shruti Hindi (https://huggingface.co/udgamlabs/Shruti, Udgam Labs, Apache-2.0),
which is itself a modified version of Cactus Whistle (https://huggingface.co/Cactus-Compute/whistle), copyright Cactus
Compute, licensed under the Apache License, Version 2.0.

Changes made by Udgam Labs: added 700 Kannada vocabulary pieces to Shruti Hindi's vocabulary and used its Hindi
language tag for Kannada; retrained all model weights on Kannada and English speech with quantisation-aware training;
exported as shruti-kannada.cact.

The model runs in the Cactus needle engine (https://huggingface.co/Cactus-Compute/needle3), Apache-2.0, which is not
included in this repository.
