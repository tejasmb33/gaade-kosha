# ಗಾದಾಮೃತ · GAADAMRUTHA

**ಗಾದೆಗಳ ಸೊಗಡಿನಲ್ಲಿ ಅನುಭವದ ಅಮೃತ.**

ನಿಮ್ಮ ಸಂದರ್ಭವನ್ನು ಕನ್ನಡ ಅಥವಾ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ತಿಳಿಸಿ; ಅದಕ್ಕೆ ಹೊಂದುವ ಕನ್ನಡ ಗಾದೆ, ಅರ್ಥ, ಉದಾಹರಣೆ ಮತ್ತು ಬಳಕೆಯ ಸಂದರ್ಭಗಳನ್ನು ತಿಳಿಯಿರಿ.

ಸ್ಥಳೀಯ ಪ್ರಸ್ತುತ ಸ್ಥಿತಿ — **19 ನವೆಂಬರ್ 2026**: 200 ಬಳಕೆದಾರ-ಅನುಮೋದಿತ ಗಾದೆಗಳು, 400 ದ್ವಿಭಾಷಾ ಸಂದರ್ಭಗಳು ಮತ್ತು 200 ದ್ವಿಭಾಷಾ ವಿವರಗಳು. ಅನುವಾದಗಳು ಮತ್ತು ಸಂದರ್ಭಗಳಿಗೆ ಸ್ವತಂತ್ರ ಭಾಷಾ ಪರಿಶೀಲನೆ ಇನ್ನೂ ಅಗತ್ಯ.

- [ದತ್ತಾಂಶ ಕಡತಗಳ ವಿವರಣೆ](project/datasets/README.md)
- [ಸಲ್ಲಿಕೆ CSVಗಳು ಮತ್ತು ಅವುಗಳ ಸ್ಥಿತಿ](project/datasets/submission/README.md)
- [ಹ್ಯಾಕಥಾನ್ ಅವಶ್ಯಕತೆಗಳ ಪರಿಶೀಲನೆ](project/testing/hackathon-requirements-audit.md)

ಸಲ್ಲಿಕೆ CSVಯ ಯಾದೃಚ್ಛಿಕ ಪ್ರದೇಶಗಳು ನಿಜವಾದ ಸಂಗ್ರಹ ಸ್ಥಳಗಳಲ್ಲ. ಮಾನವ ಧ್ವನಿ ದಾಖಲೆಗಳು ಮತ್ತು ಒಪ್ಪಿಗೆ ಪತ್ರಗಳ ಕೆಲಸ ಇನ್ನೂ ಉಳಿದಿದೆ. ಸ್ಥಳೀಯ ಬದಲಾವಣೆಗಳು hosted ಆವೃತ್ತಿಗೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನಕಲಾಗುವುದಿಲ್ಲ.
